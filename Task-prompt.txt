Задача: Архитектура на Arduino ESP32-S3 емулатор за Windows
Цел: Създаване на C++ емулатор, който предоставя Arduino-съвместим API за тестване на код за ESP32-S3 върху Windows.
Основни модули:
•	Runtime: Управление на жизнения цикъл (init, setup, loop).
•	Core: Основни типове (byte, word, String), константи и глобални дефиниции.
•	GPIO: Управление на пинове (pinMode, digitalRead/Write, analogRead/Write).
•	Serial: Емулация на Serial през Windows Console.
•	Timing: Функции за време (millis, micros, delay), базирани на std::chrono.
•	HAL (Hardware Abstraction Layer): Абстракция на системните извиквания (IConsole, ITimer).
•	Utilities: Спомагателни функции (map, constrain, tone, random, shiftIn/Out).
Изисквания:
1.	Чистота: Модулите не трябва да имат циклични зависимости.
2.	HAL Изолация: Всички Windows API извиквания се капсулират в имплементациите на HAL интерфейсите.
3.	Експозиция: Потребителят включва единствено Arduino.h (намиращ се в /include), който обединява всички модули.
4.	Разширяемост: Архитектурата трябва да позволява лесно добавяне на нови HAL имплементации в бъдеще.
Процес:
•	Проектът се разработва стриктно модул по модул.
•	Главният архитект следи за спазване на йерархията и чистотата на интерфейсите.
